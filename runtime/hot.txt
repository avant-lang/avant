# The runtime's hot functions: runtime/build.sh (place_hot) places these
# apart from the rest of the code, so a change anywhere else in the
# runtime, or in the size of what is linked before them, does not move
# them. One line per function: the object that defines it, its name.
#
# How the list is chosen: every LangArena program (the 50 tasks and their
# twins) is profiled (perf record, cycles, up to 8 s each), and a runtime
# function is listed when it takes at least 2% of one program's cycles.
# The list is by profile, not by name: a function falls off it, or comes
# onto it, when a profile says so. A name the build no longer finds stops
# the build, so the list cannot go stale silently.
