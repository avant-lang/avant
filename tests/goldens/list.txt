# The goldens of tests/goldens/ that a dump writes: one
# list, read by tests/bless_goldens.av, which writes them, and by the test
# file that checks each one, so the two cannot drift.
#
#   TEST STEM SOURCE LAYERS
#
# TEST the test file that checks the row (tests/cases/TEST.av)
# STEM tests/goldens/STEM.<layer>
# SOURCE the program, from the checkout's root
# LAYERS a comma list of tok (avant dump --tokens), ast (--ast), check
#         (--check) and mir (avant dump)
#
# A row's order is its test's order. The run goldens (tests/goldens/runs/)
# are tools/run-goldens.sh's, not listed here.
